# Dataset

This project uses the NASA C-MAPSS FD001 Turbofan Engine Degradation Dataset.

The dataset is not included in this repository due to its size and dataset distribution considerations.

## Dataset Details

- Dataset: NASA C-MAPSS FD001
- Training engines: 100
- Test engines: 100
- Sensor channels: 21
- Operating condition: 1
- Fault mode: HPC degradation

The dataset can be obtained from the NASA Prognostics Center of Excellence (PCoE).

After downloading the dataset, place the required files in this `data` folder before running the project.
